# 拾史 Shishi

桌面端文化故事创作工作台，产品目标 v1.0，当前实现为 `1.0.0-dev.7` 本地验收版。尚未部署域名。

## 本机验收

启动后打开 http://127.0.0.1:4317 。首页可选择“用示例免费测试流程”，无需 API Key，不调用付费服务。示例模式生成引用式剧本、抽象器物示意图、本机语音和真实 MP4，所有界面明确标记测试；它不是 GPT 创作效果展示。

真实创作路径：在“模型连接”选择 DeepSeek 或 OpenAI 文字服务、填写对应密钥，并配置 OpenAI 图片与配音模型、已核对的单次预留费用；设置本项目预算；上传书页或 PDF / 粘贴正文，选择真实 AI 生成，确认故事，等待分镜、图片、声音和本地成片，再审阅导出。仅保存连接不会提交付费调用。自动化测试不调用真实服务商。

## 开发与启动

需要 Node.js 24+、FFmpeg 与 FFprobe；本机免费配音测试需 Windows System.Speech 和可用语音。真实配音通过配置的 TTS 接口。

```powershell
npm ci
npm run check
npm test
npm run build
npm start
```

也可运行 `start.ps1`。单次启动同时运行 API 与独立 Worker。浏览器关闭后任务继续，但主机休眠或服务退出会暂停执行，重启从数据库恢复。默认只监听 127.0.0.1。

`.env.example` 列出配置。模型名称是可调整的默认值，需以账户可用能力验证；ChatGPT 订阅不自动提供 API Key 或接口额度。密钥保存在用户目录 .shishi/connection.secret.json 或环境变量，避免进入 WPS 项目同步目录，不进入 Git、前端和导出。

## 已实现的主流程

- SQLite 项目、偏好版本、本条覆盖、原页与文本来源、剧本版本、审批和任务持久化。
- 图片/PDF 上传、PDF 文字提取、扫描资料识读适配、逐条来源引用、手工校对。
- GPT 剧本、分镜与提示词适配器，图片生成/参考图编辑适配器、TTS 适配器。
- 独立 Worker、暂停/恢复、未知结果保护、幂等审批、保守费用预留和服务商请求跟踪。
- 1080×1920 图片运动、旁白、中文字幕、轻量合成氛围音、MP4 与 SRT。
- 字幕、音量、节奏与参考图替换的局部修改，复用既有图片和音频。
- ZIP：成片、字幕、封面、发布文案、来源、项目记录与可复用媒体。

## 验收边界

真实付费供应商尚未用真实密钥端到端验收；适配器通过模拟响应测试。当前费用以保守调用上限占用项目额度，不冒充服务商实际账单，未知请求保留预留且禁止盲目重试。

图生视频为后续条件接入，目前图片加声音可完成成片。声音气质映射、复杂历史形制质量、多人物表演、任意自然语言修改、跳过故事确认、横屏精修暂不作为已验收能力。预算不足或连接缺失时停止，不返回伪造结果。

## DeepSeek 接入

在“模型连接”选择 DeepSeek，填写独立密钥并保存。文字和照片识读通过 https://api.deepseek.com/responses，默认 deepseek-flash；结构化输出和引用校验沿用现有流程。图片与语音继续使用独立的 OpenAI 密钥。扫描 PDF 在 DeepSeek 下需转换图片或粘贴正文，避免向不支持的接口提交付费请求。无静默跨服务商回退。预算沿用当前作品设置，保存连接不发起生成。详细变更见 CHANGES-dev.2.md。

## Seedream 图片服务

在模型连接选择“Seedream · 火山方舟”，填写方舟 API Key 并保存。默认 Seedream 5.0 lite，支持单图和器物参考图，生成竖屏 PNG 并保留 AI 水印。文字继续用已选服务、配音仍用 OpenAI。切换或保存设置不重试任务、不提高项目预算。即梦网页会员凭证不等于方舟 API Key。详细契约、验证及未完成的真实验收见 CHANGES-dev.4.md。

## IndexTTS 本机配音

在“模型连接”选择 IndexTTS 本机，保存地址 http://127.0.0.1:9880。安装模型和环境后可点击“启动本机配音”及“检测配音服务”；可上传2–30秒清晰参考声音。配音在本机GPU运行，不扣云端API预算。服务不可用时阻塞，不静默使用OpenAI。

本机桥接协议由拾史提供，不是直接兼容任意第三方IndexTTS HTTP服务。部署规格和当前验证边界见 CHANGES-dev.5.md；未完成真实推理前，不应将界面已接入等同于模型已可用。

## 版本与文档

`docs/v1.0` 是原设计基线，保留 PRD、技术规格、架构图、原型、契约和校验工具，不修改冻结文件。当前实现状态及差异见 `IMPLEMENTATION.md`。开发提交使用独立版本标签，验收后再建立正式发布版本和域名部署。

`runtime/`、`.env`、`node_modules/`、`dist/` 与 `qa/` 不纳入 Git。runtime 内含用户资料、SQLite 数据库和媒体，应单独备份；不能用 Git 回退替代数据库恢复。
