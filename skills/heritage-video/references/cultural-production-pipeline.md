## 可借鉴的结构

火宝将剧本改写、实体提取、分镜、提示词拆为四种 Agent 职责，通过工具读写项目数据。借鉴职责与数据交接，不默认真的启动四个代理，也不把每个步骤写成独立长对话。

采用稳定 ID 管理角色、场景、道具；镜头绑定具体 ID 与参考图。区分人物外貌与妆造、场景空间与光线、道具形制与剧情用途。别名归一化后复用，防止同一高渐离多套脸或同一筑反复重建。身份去重与镜头叙事去重分别验收。

将“叙事节拍 → 生成段落 → 子镜头 → 素材版本”分层。一个生成段落围绕连续空间和因果链，含铺垫、动作、反应；不能把30张关键画面等同30个视频任务。8–15秒、多子镜头只是火宝的策略，按当前模型能力和实际配音调整；复杂挥击等先测试单动作，不强制每3秒切镜。

静态提示词负责一个时刻的构图、器形和识别特征；视频提示词增加动作起止、空间关系、运镜、切点与结尾状态。不要直接把静态描述送作动态指令。精确文字、文物铭文、技术剖面由可控后期或可靠资料呈现。

提示词从已经批准的镜头描述派生，不新增人物、台词、知识断言或画面事件。模型适配层只转换参数与引用格式；内部 @角色/@道具 是实体标记，必须转换为服务实际支持的引用格式，不能假定各平台都认识 @名字。

## 面向书籍与文物的必要补充

1. 书页登记来源、页码、原文主张、配图权属与引用范围；OCR人工核对后进入事实表。书中的文学推断不能直接变成考古结论。
2. 每片一个中心问题。多文物只有在共同证明该问题、并明确解释彼此关系时才能同片；不能因资料丰富就插入无因果关系的支线。
3. 事实层、改编层和视觉层分开：知识主张有 evidence_id；原创对白标创作；服饰、宫殿、失传器物标艺术复原。文物本身既是实体，也可能是证据，需记录两种角色。
4. 海外版本先解释观众不知道的概念，再用人名或术语。先保留语义与悬念，再本地化语言；中文时长不可直接套英语。界面多语言或翻译提示词不等于完成文化本地化。

## 声画共同时间线

建立唯一对齐表：segment_id、shot_id、locale、旁白原文、audio_file、实测 start/end、字幕原文及 cue、画面动作、证据编号、采用素材版本、验收状态。

先用短样确定旁白音色、情绪、发音，再锁定音频版本。通过音频边界、ASR或强制对齐获取句/词时码，人工检查人名与知识术语。按字数比例分配字幕只能是临时估算，不得标成精准对齐。

同一语句的字幕与对应画面共用实测时间：介绍击筑显示击弦，讲起身显示起身，讲未中显示明确落空或反应。语速估计只用于预算，不能替代音频测量；不能平均分图像时长。合成前检查累计帧舍入漂移，在统一时基上校正切点。

用户当前默认字幕：1080×1920时约42px、短句单行、左对齐，参考锚点 x=100/y=1490，随主体和平台安全区复验；这是本系列偏好，非所有视频的固定标准。声音必须试听，神经合成不称真人，原生视频音轨不等于已锁定准确旁白。

## 任务与工具路由

为每次生成保存 task_id、供应商/model、实际请求参数、输入版本、输出本地路径、费用/积分、状态与错误。生成完成、下载完成、素材验收通过是三个状态。数据库记录有助追踪，不自动证明持久队列、跨重启续跑或付费幂等。

只修改失败或受上游变化影响的节点；改字幕无需重生画面，换旁白优先调整时码与剪辑。提交超时先查询原任务，重启后先对账，避免盲重发。模型配置失效时不得静默换模型导致风格与成本变化。

当前火宝适配器实际注册图像 OpenAI/Gemini/Volcengine，视频 Volcengine/MiniMax/Aliyun。MiniMax适配器写有H3请求、轮询、多模态引用与参数校验，不能据此声称本机已接入或已验证官方最新能力。即梦会员网页权益不等于火山API额度；分别核实账号、入口、授权、积分。

模型按环节选：已有合格图复用；关键动作小样比较H3/即梦；主力视频模型尽量统一；精确旁白使用独立音频链；剪映或本地渲染负责时间线。原生音频默认行为应显式检查，避免生成旁白与外部旁白叠加。

## 正式交付门槛

火宝 ffmpeg-merge 会按镜号拼接存在视频的镜头并允许跳过未生成项；本流程只允许在预览使用此策略。正式导出前，计划中所有必要镜头须有通过版本，缺失/不合格清单为零；任何删镜必须同步改剧本与旁白。

火宝当前移除独立TTS与配音角色工具；schema保留subtitleUrl不证明存在强制对齐功能。其拼接服务执行FFmpeg串接、转码和时长探测，不承担文博事实、字幕准确或情绪审片。应独立完成配音、字幕、音量、画音一致、完整播放与语言验收。

采用顺序：先单片数据清单和对齐表，再建立角色/器物资产库与模型任务记录，再做可编辑时间线，最后才考虑部署平台。先用一个60–90秒作品验证闭环，避免在作品尚未通过前扩成复杂平台。
