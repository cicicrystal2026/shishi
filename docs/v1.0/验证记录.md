## 复现方式

使用 Python 及 tests/requirements.txt 指定的 jsonschema 4.26.0 运行测试。文档构建需要 python-docx，图像构建需要 Pillow，原型截图需要 Playwright 与可用 Chromium。当前机器使用 Codex 提供的运行时和库；同步检查本身只使用 Python 标准库。

先执行 `python tools/check_sync.py` 检查版本与受控文件，再执行 `python tests/test_design_contracts.py` 和 `python tests/test_sync_guard.py`。构建和测试不需要提交任何付费生成任务。
