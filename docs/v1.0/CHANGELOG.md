# 拾史变更日志

## v1.0 2026年10月24日

阶段：设计基线。CHG-001：确立首版桌面产品需求、原型和技术架构的统一版本管理。

- 产品：保留默认偏好、材料输入、故事确认、后台制作、成片审阅和导出；分镜详情按需进入。
- 需求：F01–F42 保持原有产品行为；新增文档同步和追踪规则，不增加用户操作。
- 设计：八个页面、两个异常状态，原型统一标识 v1.0。
- 架构：十个逻辑模块，模块化单体加 Worker，默认 GPT 文字及图片工具适配，视频 API 条件启用。
- 规格：补齐开发技术规格书、OpenAPI、阶段 JSON Schema、SQLite 设计 DDL 和验收映射。
- 版本：独立本地 Git、需求追踪、文件清单、不可覆盖快照和版本标签。
- 验证范围：需求与架构设计映射、版本与文件同步、原型交互及文档视觉检查。所有应用需求仍为 design_only，真实 AI、任务、预算、迁移和成片能力尚未实现验收。
- 验证结果：11 项契约测试和 5 项同步故障检查通过；PRD 15 页、技术规格书 16 页已逐页检查，详见 验证记录.md。
- 兼容性：无运行数据库，无历史用户项目迁移；不配置远程仓库，不提交密钥或用户书页。

本次设计影响评审由 Codex 执行；用户对新增技术架构的验收尚未记录，不将本次交付视为技术方案已获最终确认。
