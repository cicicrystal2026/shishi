# 拾史迭代记录

## CHG-001 建立 v1.0 设计基线

来源：用户要求补充技术架构图，并与 PRD 严格同步，支持持续迭代。

目标：需求、页面、架构、验收和交付文件可以相互定位；修改不同步时能被检查发现；旧版可找回。

影响：PRD 增加版本同步章节和基线元数据；原型仅统一版本标签，不更改既有产品行为；增加架构图、技术说明、追踪与校验工具。F01–F42 的业务内容不变。

数据兼容：当前没有真实运行数据库；记录未来迁移、Skill、模型配置与内容快照规则。

验证：设计映射、同步脚本及其故障检测、原型交互回归、Word 与图像视觉检查。具体基线文件以 release_manifest.json 和 Git 标签为准。
